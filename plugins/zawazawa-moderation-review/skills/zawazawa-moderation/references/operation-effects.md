# ZAWAZAWA操作の効果

この文書は、ZAWAZAWAの各操作が掲示板と利用者へ及ぼす効果を定める正本である。どの操作を対処案に含めるかを判断するときに読む。

| 操作           | 効果                                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 削除           | 投稿を公開画面から削除する。管理画面から復元でき、完全消去の操作はない。                                                           |
| 復元           | 削除済み投稿を復元する。                                                                                                           |
| 自動無視       | 設定後の対象投稿者のコメントを、本人に気づかせずに他の利用者から隠す。設定前の投稿には遡及しない。                                 |
| 自動無視の解除 | 対象投稿者への自動無視設定を解除する。                                                                                             |
| ブロック       | 管理画面で選択した接続元を基準にゲスト投稿を制限し、対象者は投稿ができなくなる。                                                   |
| ブロックの解除 | 選択したゲスト投稿制限を解除する。                                                                                                 |
| 通報の完了     | 通報を処理済みにする。完了ボタンを押した後の最終確認で対処メッセージを入力できる（任意）。対象コメントを削除しない場合にも使える。 |
| 通報の無視     | 対処メッセージを返さず通報を処理する。通報者には通報が放置されたように見え、その通報者は同じ対象を再通報できなくなる。             |
| 公開警告・案内 | 承認された本文を掲示板へ投稿する。                                                                                                 |
