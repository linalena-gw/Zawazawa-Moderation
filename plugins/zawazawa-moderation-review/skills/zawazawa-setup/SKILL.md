# ZAWAZAWA Setup

初回設定を、設定ファイルの手編集なしで安全に完了させる。詳細な工程は[初回設定手順](references/setup-flow.md)を読み、その順序と停止条件に従う。

利用者に求める操作は、保存先と運用基準の確認、必要なソフトウェア導入の承認、必要時のCodexアプリ再起動と初回設定の再開、ZAWAZAWAへの本人ログインに限る。認証情報を会話、設定、運用フォルダへ書かない。

依存関係の確認と導入が済むまではMCPツールを呼び出さない。プラグインのMCPサーバーが依存関係不足で起動していない場合も、存在しないツールを推測して呼ばず、[初回設定手順](references/setup-flow.md)に従って再起動後に再開する。プラグインの場所は実際に読み込まれたこのskillの場所を基準に特定し、リポジトリのソースツリーや運用フォルダを代わりのインストール先として使わない。

既に作成済みの項目は検査して再利用し、同じ質問を繰り返さない。利用者が編集した`運用基準.md`は上書きせず、その内容を正本として再利用する。その他の生成物に差分がある場合は上書きせず、差分と必要な判断を示して止める。
