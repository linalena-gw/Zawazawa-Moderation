# ZAWAZAWA Setup

初回設定を、設定ファイルの手編集なしで安全に完了させる。詳細な工程は[初回設定手順](references/setup-flow.md)を読み、その順序と停止条件に従う。

利用者に求める操作は、保存先と運用基準の確認、必要なソフトウェア導入の承認、必要時のCodexアプリ再起動と初回設定の再開、ZAWAZAWAへの本人ログインに限る。認証情報を会話、設定、運用フォルダへ書かない。

最初に[初回設定手順](references/setup-flow.md)に従い、プラグインのランチャーから永続ランタイムの準備済み状態を確認する。準備済みランタイムが無い場合、または現在のプラグインコードに対応しない場合だけ、利用者が承認したソフトウェア取得を伴う準備を行う。プラグインキャッシュが作り直されても同じコード用のランタイムが準備済みなら再導入しない。MCPサーバーの通常起動中にnpm依存関係やChromiumをネットワーク取得させない。新しいランタイムを準備した後は、Codexの再起動が必要と案内してから同じチャットで設定を再開する。

プラグインの場所は実際に読み込まれたこのskillの場所を基準に特定する。運用コマンド、認証、依存関係確認、診断は、ランチャーが返す永続ランタイムのルートを使う。リポジトリのソースツリーや運用フォルダを実行時ランタイムの代わりに使わない。MCPツールが見えない場合は、存在を推測して呼ばず、同じ手順でランタイム状態を確認する。

既に作成済みの項目は検査して再利用し、同じ質問を繰り返さない。利用者が編集した`運用基準.md`は上書きせず、その内容を正本として再利用する。その他の生成物に差分がある場合は上書きせず、差分と必要な判断を示して止める。
