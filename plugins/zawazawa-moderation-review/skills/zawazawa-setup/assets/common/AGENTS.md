# AGENTS.md

## 対象

このフォルダは、直下の`zawazawa.config.json`が示す一つのZAWAZAWAグループだけを扱う。対象、表示名、運用モードを会話や推測で置き換えない。

## 正本

- 現在の違反判断と処置候補は`運用基準.md`だけを使う。
- `根拠資料.md`と`判断事例.md`は、最終判断が初期案と異なり、基準の一般化を検討するときだけ読む。
- 調査、承認、実行は`zawazawa-moderation` skillに従う。

## 保存禁止情報

通報者の表示名とトリップは理由本文へ混ぜず、判断事例、Git履歴、公開文面、一覧UIへ書かない。接続元情報、通信先の内部情報、User-Agent、セッション、Cookie、パスワード、トークンは回答を含めて保存・表示しない。

## 変更

ZAWAZAWA上の操作承認を、運用基準、根拠資料、判断事例、設定ファイルの変更承認に流用しない。文書や設定の変更は具体的な差分を提示し、別の明示承認を得る。
