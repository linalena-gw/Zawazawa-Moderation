# ZAWAZAWA通報対応 運用フォルダ

このフォルダは、一つのWikiに対するZAWAZAWA通報対応の設定と判断基準を置く。プラグイン本体や認証情報は置かない。

## 文書地図

- `zawazawa.config.json`: 対象グループ、表示名、運用モードの正本
- `運用基準.md`: 通常の通報対応で使うWiki固有の判断基準
- `根拠資料.md`: 運用基準を見直すときだけ使う証拠台帳
- `判断事例.md`: 将来も再検討する価値がある境界事例だけを記録する追記専用文書
- `AGENTS.md`: AI作業者が守る安全制約

通常は`$zawazawa-moderation`へ「未処理のZAWAZAWA通報を調べて」と依頼する。初期状態は必ず`restricted`であり、一覧で管理者が判断を送信するまでZAWAZAWAを変更しない。

`moderation-reports/`には投稿本文と通報理由が含まれるため、共有やGit管理をしない。
