# ZAWAZAWA通報対応 運用基準

この文書は、Wiki固有の事実から、コメント・投稿者・通報へどの処置を候補にするかを定める正本である。調査・承認・実行の方法は`zawazawa-moderation` skillが担う。

## 1. コメントの処置基準

### 1.1 [ZAWAZAWA利用規約 第6条](https://z.wikiwiki.jp/s/agreement)より

以下に該当するコメントは削除する。

1. 過度に暴力的または残虐または猥褻な表現
2. 利用者またはその他の第三者の名誉または信用を毀損する表現
3. 差別・自殺・自傷行為・薬物の不適切な利用の助長
4. 反社会的な表現
5. チェーンメール等の第三者への情報の拡散を求める情報
6. 他人に不快感を与える表現
7. 面識のない異性との出会いを目的とした情報
8. なりすまし
9. ZAWAZAWAが事前に許諾しない宣伝、広告、勧誘、または営業行為

### 1.2 [WIKIWIKI 本サービスに関する利用のルール](https://wikiwiki.jp/pp/rules)より

- ゲーム内容やキャラクターへの否定的評価の書き込みは、具体的であることが必要であり、その上で侮辱的な表現を含んではならない。

### 1.3 慣行

煽り・中傷に属するもの：

1. 不満への同調や対立を意図的に煽ったり、意図的な誤情報・情報操作・挑発の反復によって議論を混乱させようとする投稿は削除する。
2. 煽りや議論妨害の目的性は、対象本文に加えて投稿履歴からの類推と、返信の流れから遡及的に判断する。
3. キャラクター並びに実在の人物や集団・団体への誹謗中傷は削除する。
4. ネットミームを用いた中傷と思われるものについてはweb検索でミーム内容を確認の上対処する。

具体性のある不満や否定への対応：

1. 1.2における「具体的」とは、対象となる仕様・挙動・出来事を示すだけでなく、実際に観察できる事実や体験と、その事実を問題と評価する理由との関係が示されていることをいう。第三者が内容を理解し、反論または検証できる程度の説明が必要である。
2. 次の要素だけでは、具体的とは扱わない。

   - キャラクター、コンテンツ、機能などの固有名を挙げること
   - 「品質が低い」「盛り上がっていない」などの印象だけを述べること
   - ユーザーテストの有無、利用者の離脱、運営の意図など、確認できない事情を根拠なく推測すること
   - 比較基準を示さず、別作品の方が優れていると断定すること
3. 具体的な内容が含まれていても、誹謗中傷などの不適切要素が含まれているなら不適切な投稿とする。

その他慣行：

- 単発の板違いのみを理由にした削除・規制はしないが、板に無関係・場違いな内容の投稿を繰り返している場合は自動無視を行う。
- リーク情報またはバグ悪用を推奨する投稿は削除する。リークとしての通報では、実際のリーク該当性を公式情報との照合結果から判断する。
- 投稿者に返信する形での警告は行わない。投稿者が見る保証がなく、反論の余地があると管理者の負担が増えるため。

## 2. 関連コメントの処置

- 親コメントだけを削除すると枝の文脈が失われる場合は、枝自体の違反性とは分けて、文脈整理としてツリー全体を削除候補にできる。枝投稿者への措置として扱わない。
- 不適切なコメントを発見した際は通報対象でなくとも処置する。たとえば通報対象のコメントに処置を行わない場合も、ツリー確認時に発見した他の不適切なコメントは処置する。

## 3. 投稿者への継続措置

コメント単体を削除候補とした後の投稿者措置は、投稿履歴と過去対応を判断対象とする。過去対応は管理画面のコメント履歴のみで確認する。この際、削除済みコメントの内容は見えないが、投稿者本人ではなく管理者が削除したという事実および寄せられた通報をもって、不適切だったと判断して良い。

- 同じ違反類型または煽り・議論妨害の目的を共有する削除候補投稿が複数ある場合、または削除等の対応後に同じ類型・目的の投稿を繰り返した場合は、自動無視を行う。
- 個々には削除閾値未満でも煽りや議論妨害が反復している場合は、目的性、頻度、期間、会話への影響、過去対応後の行動から、全体として継続的な妨害かを判断する。継続的な妨害であれば自動無視を行う。
- 違反でない投稿の多さは、上記の反復・継続妨害の評価を打ち消す理由にしない。
- ブロックは通常の候補にしない。大量投稿または継続的攻撃があり、かつ自動無視だけでは抑止できない場合だけ、理由を示して候補にする。

## 4. 通報者への対応

### 4.1 対処メッセージ

対処メッセージの表現と開示範囲は`zawazawa-moderation` skillの「通報への対処メッセージ」に従う。Wiki独自の案内が必要な場合だけ、この節へ追記する。

### 4.2 通報の無視

- 削除しない旨を対処メッセージで回答済みの同一投稿を、同じ通報者が再度通報した場合は無視を行う。
