# 初回設定手順

この手順は、macOSまたはWindowsのローカル環境で初回設定を行う。Web・モバイルだけの環境、Linux、管理権限を持たない利用者では実操作を始めない。

## 1. 実行環境

1. OSを確認する。macOSとWindows以外では正式対応外であることを伝え、設定を変更せず止める。
2. `node --version`と`npm --version`を確認する。Node.js 24未満またはnpmが無い場合は、Node.js 24 LTSの公式配布物を導入する必要、外部通信、管理者権限が求められる場合があることを説明し、明示的な承認を得る。
3. 承認後だけ公式のNode.js配布元を使う。非公式インストーラーや任意のシェルスクリプトを使わない。インストーラー操作やホスト再起動が必要なら利用者へ依頼し、再開後に版を読み戻す。
4. プラグインルートで`npm ls --depth=0`とPlaywrightの専用Chromium実体を確認する。不足またはlockfileとの不一致がある場合だけ`npm ci`を実行する。これはlockfileの依存関係と専用Chromiumを導入する。失敗した場合は成功したことにせず、原因を示して止める。

## 2. 運用フォルダの候補

未確定の値だけをまとめて尋ねる。

- 新しく作る専用フォルダの絶対パス
- `https://z.wikiwiki.jp/m/<グループキー>/...`形式の管理画面URL
- 一覧と報告に出すWiki表示名

同梱の統一テンプレートを初期案として使い、初期モードは`restricted`固定にする。テンプレートには著者の原神Wiki由来の慣行が含まれるため、対象Wikiに合わせて全文を確認し、必要な修正を利用者と確定する。初回設定中に`autonomous`を提案したり、選択肢へ加えたりしない。

セットアップスクリプトを最初に`--dry-run`で実行する。

再開時も`--dry-run`を省略しない。編集済みの`運用基準.md`はスクリプトから`preserve`として報告されるが、これは承認済みの差分を意味しない。前回の承認済み編集と現在の差分が一致し、固定名の生成物がすべて揃い、設定が`restricted`であることを別途確認できた場合に限り、次の未完了工程へ進む。承認内容を確認できない場合、未管理の項目、生成物の不足、その他の内容差分が一つでもある場合は、再開済みと推測せず止める。

```text
node <このskill>/scripts/init-workspace.mjs \
  --destination <絶対パス> \
  --admin-url <管理画面URL> \
  --display-name <Wiki表示名> \
  --dry-run
```

返されたファイル一覧、抽出したグループキー、統一テンプレート、`restricted`で作ることを示す。衝突があれば上書きせず、そのファイルと理由を伝える。

## 3. 運用基準の確認と生成

統一テンプレートの`運用基準.md`を全文読み、節ごとの要点を示す。利用者が修正を求めた場合は、生成前に具体的な差分を提示して承認を得る。テンプレートをそのまま使うか、提示済み差分を採用するかが確定するまで`--apply`を使わない。

確定後、同じ引数で`--apply`を実行する。テンプレートへの変更がある場合は、生成後の運用フォルダにある`運用基準.md`だけへ承認済み差分を反映し、全文を読み戻す。他の生成ファイルへ承認を流用しない。

生成物には認証情報を入れない。`根拠資料.md`と空の`判断事例.md`は基準保守時だけ使い、通常の通報対応では読まない。

## 4. 認証と確認

1. プラグインルートで`npm run auth:zawazawa -- <グループキー>`を実行する。
2. 開いた専用ブラウザで、利用者本人にログインと対象グループの確認をしてもらう。Cookie、パスワード、トークンを会話へ貼らせない。
3. 運用フォルダの`zawazawa.config.json`の絶対パスを`get_moderation_target_config`へ渡し、表示名、グループキー、`restricted`を読み戻す。
4. 認証済みの読み取り専用入口で接続を確認する。通報への変更、一覧判断の送信、実行ツールは呼ばない。

完了時は、作成したフォルダ、テンプレート、対象、`restricted`、認証・接続の結果を一行ずつ示し、次の依頼例としてCodexでは「`$zawazawa-moderation`」、Claude Codeでは「`/zawazawa-moderation-review:zawazawa-moderation`」の使用を案内する。特に追加の指示がなければ、未処理のZAWAZAWA通報を調べる挙動になると説明する。
